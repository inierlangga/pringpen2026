# Workspace Rules for PRINGPEN 2026

## Deployment & Vercel Push Rules
- **Deployment Constraint**: Hanya lakukan push / deploy ke Vercel ketika pengguna secara eksplisit mengirimkan chat "push".
- Jangan pernah melakukan deployment atau push otomatis ke Vercel tanpa instruksi chat eksplisit "push" dari pengguna.
