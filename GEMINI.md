# Workspace Rules for PRINGPEN 2026

## Git & Deployment Rules
- **Strict Push & Commit Constraint**: Jangan pernah melakukan `git commit` atau `git push` secara otomatis.
- Hanya lakukan `git add`, `git commit`, dan `git push` (deploy ke GitHub & Vercel) ketika pengguna secara eksplisit mengirimkan chat "push".
- Biarkan semua perubahan file tetap berada di local working directory tanpa proses git sampai ada instruksi chat eksplisit "push".
